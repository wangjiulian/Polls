# 🗳️ Django Voting System

A web-based voting system built with Django. Users can browse poll questions, vote on choices, and view real-time results. This project is ideal for learning the Django framework's core components including models, views, templates, and the admin interface.

---

## 🌟 Features

- View poll questions and associated choices
- Submit votes as a user
- Display voting results
- Admin interface for managing questions and choices
- Lightweight setup using SQLite for easy development

---

## 🏗️ Tech Stack

- Python 3.x
- Django 4.x+
- SQLite (default database)
- HTML & Django Template Language
